# Product Overview

LeCodeR is an open-source web application that automatically transforms academic research papers into working code repositories using AI.

## Core Features
- PDF upload and text extraction with drag-and-drop interface
- 6-stage AI pipeline for comprehensive paper analysis
- Real-time progress tracking during processing
- Complete executable code generation (no placeholders)
- Project management dashboard
- Multi-LLM support (OpenAI, Google Gemini, Claude)

## User Flow
1. Upload research paper PDF
2. AI processes through 6 stages: concept extraction, architecture design, implementation planning, code generation, testing, and documentation
3. Track progress in real-time
4. Download complete working repository

## Target Users
- Researchers wanting to prototype ideas from papers
- Developers exploring academic concepts
- Students learning from research implementations
